# App translation: English ships by default, Spanish is one toggle away

Status: in progress. Every user-visible string in `web/src` moves into a typed message catalogue with an English and a
neutral-Spanish entry. The language is a device preference rendered as a toggle beside the theme toggle.

## Specs

**S1 — English is the default and the fallback.** A rule: `appearance.language` is `"en"` unless the user chooses
`"es"`, and `useT()` outside a provider answers English, so every existing test keeps running unchanged and a missing
Spanish key can never render a blank.

**S2 — One file per domain, so translators never collide.** A rule: each domain owns
`web/src/i18n/messages/<domain>.ts`, exporting `{ en, es }` with keys prefixed by the domain. `messages/index.ts` merges
them. A key that exists in `en` and is missing in `es` falls back to English at read time, so a half-translated surface
degrades instead of breaking.

**S3 — The Spanish is neutral.** The user's words: "español neutro nada de voceo argentino". A rule: second person is
`tú`, never `vos`; no regional slang, no `che`, no voseo verb forms (`tenés`, `podés`, `hacé` are forbidden). Technical
nouns stay recognisable (`bloque`, `rutina`, `hábito`, `tarea`, `proyecto`), sentences stay short, and the tone matches
the English one: direct, no exclamation marks, no filler.

**S4 — The toggle sits beside the theme toggle.** A rule: `LanguageToggle` renders in every section header that already
renders `ThemeToggle`, is keyboard reachable, and announces what it will switch to in the language currently shown.

**S5 — Dates and numbers follow the language.** A rule: any `Intl` formatting in a translated surface takes its locale
from `useT()` (`en-US`, `es-MX`) instead of hardcoding `"en"`, so weekday names and date labels switch with the language.

**S6 — Nothing is half-migrated silently.** A rule: a surface is done when no user-visible English literal remains in
its files, `pnpm --filter @chub/web typecheck` is clean, and its focused tests still pass. `aria-label`, `title`,
`placeholder` and `alt` count as user-visible.

## Tasks

- **T1 — Shell** (`components/layout`, `features/pages`, `features/home`, `features/search`, `features/trash`):
  messages `shell`, `notes`, `home`, `search`, `trash`; the toggle in the shell and in Home. Delegated.
- **T2 — Habits and Books**: messages `habits`, `books`; the toggle in both headers. Delegated.
- **T3 — Projects, Tasks and Goals**: messages `projects`, `tasks`, `goals`; the toggle in every header of those
  sections, including the board and goal pages. Delegated.
- **T4 — Routine and Settings**: messages `routine`, `settings`; the toggle in both headers, including the preference
  labels and descriptions rendered by the settings screen. Delegated.
- **T5 — Gate.** Both suites, both typechecks, build.

## Log

**L1 — What this wave actually had to survive.** Nine delegated units, several of them partial on the first pass. Three
classes of defect recurred and are worth remembering: a worker produced duplicate catalogue keys that broke `tsc`
(TS1117) and was deduplicated by script; copy migrations kept "improving" the English, which broke tests asserting the
old text — the rule that settled it is that the English value must reproduce the previous literal character for
character, because only Spanish is new; and two surfaces were owned by nobody until the sweep found them (the page
editor, then the vendored block toolbar and toast). Two devices settled most arguments: the two greps for user-visible
literals, and `comm -23` between `t("domain.…")` uses and the keys the catalogue defines — a key used but not defined
renders as `routine.missed` on screen, which no test and no typecheck catches. Four literals remain, all in components
reachable only from the dev lab (`BoardCanvas`, `GraphHeatmap`) and documented as out of scope.

**L2 — Measured result.** Server 190 tests and web 432 tests green, both typechecks clean, build green. Thirteen
domains, all with exact key parity: notes 123, routine 145, goals 169, projects 130, tasks 117, habits 111, books 90,
settings 69, editor 23, trash 20, shell 19, search 12, home 5 — roughly a thousand keys in two languages, zero
user-visible literals left in production surfaces, and zero keys used without being defined. The entry chunk grew from
1,696.76 kB to 1,788.84 kB (533 → 558 kB gzip) because the whole catalogue is merged and the provider mounts at the
root: every section's strings ship to every visitor, including sections that are lazily loaded. That is a deliberate
trade for no flash of English on switch; the alternative, loading the Spanish dictionary on demand, is a later
optimisation with a real cost of its own.
